# Delfira Karnain — Portfolio

A responsive, single-page portfolio built with static HTML, CSS, and JavaScript. The page defaults to Indonesian and includes an ID | EN language toggle.

## Run locally

Open `index.html` in a browser. No build step, package installation, or backend is required.

## Content

Biographical and achievement details are based on the supplied resume content. Contact links are email and LinkedIn only; no phone number or contact form is included.
